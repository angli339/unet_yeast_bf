## Weights

Model weights are available at https://huggingface.co/angli339/unet_yeast_bf

Description of the files:

* `unet_yeast_bf.h5`: Model weights (float32 precision) in Keras HDF5 format.
* `unet_yeast_bf_float16.h5`: Model weights (float16 precision) in Keras HDF5 format.
* `unet_yeast_bf_float16/1`: Full model as TensorFlow SavedModel (float16 precision).
